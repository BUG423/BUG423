### 👨‍💻 关于我

我是厦门大学硕士研究生，研究方向为**人工智能与惯性定位**。核心研究聚焦于数据驱动的惯性里程计（Inertial Odometry）、非线性复杂运动条件下的鲁棒轨迹估计，以及端侧轻量化深度学习与多传感器融合算法。

同时，拥有从底层电路硬件设计（立创EDA硬件量产）、固件驱动开发到上层图形化低代码平台与全栈应用的完整工程实现能力。

- 🎓 **学历背景**：
  - **2023.09 – 2026.06** · 厦门大学信息学院，通信工程，**工学硕士**
  - **2019.09 – 2023.06** · 厦门大学电子科学与技术学院，电子信息科学与技术，**工学学士**
- 🔬 **研究重点**：神经网络惯性里程计、多模态时频特征融合、端侧移动端位姿解算
- 🛠️ **核心技术栈**：Python, C/C++, PyTorch, Linux, Git, Docker, ESP32, 树莓派, 立创EDA
- 🤝 **学术与技术交流**：欢迎围绕惯性导航、定位算法、嵌入式智能开展学术交流与项目合作！
